

# Procedure EFD算法数学原理

好的，我们来深入剖析 **Procedure EFD (Exact Fault Detection)** 算法背后的**数学原理**。这部分内容是现代故障诊断线性综合理论的基石。

该算法的精髓在于将一个复杂的、多目标的滤波器设计问题，通过一系列精巧的代数变换，分解为三个独立的、可求解的数学子问题。其核心是基于**代数系统理论**，特别是**零空间方法 (Nullspace Method)**、**多项式矩阵理论 (Polynomial Matrix Theory)** 和**互质分解 (Coprime Factorization)**。

------

## **1. 问题的数学描述：EFDP**

首先，我们将问题形式化。给定一个线性系统：

 $y(s) = G_u(s)u(s) + G_d(s)d(s) + G_f(s)f(s)$

 我们要寻找一个稳定且正规的滤波器 $Q(s)$，使得残差 $r(s) = Q(s)y(s)$ 满足：

1. **干扰解耦**：
    $Q(s) [G_u(s) \quad G_d(s)] = 0$
2. **故障敏感**：
    $Q(s) G_f(s) \neq 0$
3. **阶数最小**：
    $Q(s)$ 的 **McMillan 阶数**应尽可能小。

这是一个约束优化问题。Procedure EFD 通过将 $Q(s)$ 分解为三个因子的乘积来解决它，每个因子解决一个子问题：
 $Q(s) = \underbrace{Q_3(s)}_{\text{动态配置}} \cdot \underbrace{Q_2(s)}_{\text{降阶优化}} \cdot \underbrace{Q_1(s)}_{\text{干扰解耦}}$

------

## **2. 数学原理之一：$Q_1(s)$ 的解耦原理 —— 左零空间**

**问题**：如何让一个信号的输出为零？
 **原理**：线性代数告诉我们，对于方程 $Ax=b$，如果我们想让输出 $y=c^T x$ 为零，就需要找到一个向量 $c$，使得 $c^T A = 0$。这个 $c$ 就在 $A^T$ 的**左零空间**中。

对于动态系统，这个原理同样适用。

* 干扰解耦条件 $Q [G_u ; G_d] = 0$ 意味着 $Q$ 必须是矩阵 $[G_u ; G_d]$ 的**左零空间基 (Left Nullspace Basis)** 的一个线性组合。
* **$Q_1(s)$ 的作用**：计算 $[G_u(s) ; G_d(s)]$ 的一个左零空间基，记为 $N_L(s)$。这个 $N_L(s)$ 就是我们的初步滤波器 $Q_1(s)$。
* **结果**：经过 $Q_1$ 作用后，系统被投影到一个子空间，该子空间与 $u$ 和 $d$ 的影响完全正交。新的“虚拟”残差 $r_1 = Q_1 y$ 只与故障有关：
   $r_1(s) = \underbrace{(Q_1(s) G_f(s))}_{R_f(s)} f(s)$
   至此，我们得到了一个虽然能用，但可能阶数很高、有多路输出且不一定稳定的初步解。

------

## **3. 数学原理之二：$Q_2(s)$ 的降阶原理 —— 最小多项式基与 McMillan 阶**

**问题**：如何从多路高阶信号中，组合出最简单的单路信号？
 **原理**：这涉及到**多项式矩阵理论**和 **McMillan 阶**。

* **McMillan 阶**：是一个传递函数的“真实”阶数，等于其最小状态空间实现的维数。
* **最小多项式基 (Minimal Polynomial Basis)**：$Q_1(s)$ 本身可以被计算为一个特殊的基，其行向量是多项式向量，且它们的阶数之和最小。每一行向量的阶数（最高次幂）是已知的。
* **$Q_2(s)$ 的作用**：寻找一个行向量 $Q_2(s)$，与矩阵 $Q_1(s)$ 相乘后，得到的单输出滤波器 $Q_{new}(s) = Q_2(s)Q_1(s)$ 的 McMillan 阶数最小。
* **求解方法 (Minimal Cover Problem)**：
  * 我们希望 $Q_2 Q_1 G_f \neq 0$，即 $Q_2 R_f \neq 0$。
  * 这意味着 $Q_2$ 不能位于 $R_f$ 的左零空间中。
  * 为了使阶数最小，我们应该优先使用 $Q_1$ 中阶数较低的行向量来构造 $Q_2$。
  * 算法会系统地搜索 $Q_2$ 的系数，从零阶（常数）组合开始，逐步增加阶数，直到找到一个满足 $Q_2 R_f \neq 0$ 且阶数最低的 $Q_2$。
  * 这就是 `efdsyn` 代码中 `glmcover1` 函数所解决的**最小覆盖问题**，是 Varga 理论的核心贡献之一。

------

## **4. 数学原理之三：$Q_3(s)$ 的镇定原理 —— 互质分解**

**问题**：如何修复一个不稳定或非因果的系统，而不改变它的零点结构（即解耦特性）？
 **原理**：**左互质分解 (Left Coprime Factorization, LCF)**。

* 任何一个有理传递函数矩阵 $G(s)$ 都可以分解为：
   $G(s) = M(s)^{-1} N(s)$
   其中 $M(s)$ 和 $N(s)$ 是**稳定且正规 (Stable and Proper)** 的传递函数矩阵，并且它们是“左互质”的（不存在非单位的公共左因子）。
* **物理意义**：
  * $N(s)$ 包含了 $G(s)$ 所有的**零点信息**（对应解耦特性）。
  * $M(s)$ 的零点对应 $G(s)$ 的**极点信息**（对应动态特性和稳定性）。
* **$Q_3(s)$ 的作用**：
  * 我们将前两步得到的滤波器 $Q_{new} = Q_2 Q_1$ 进行左互质分解：$Q_{new} = M^{-1} \tilde{Q}$。
  * $M(s)$ “吸收”了所有的不稳定极点和非正规性。
  * $\tilde{Q}(s)$ 是一个稳定且正规的滤波器，且它与 $Q_{new}$ 具有完全相同的零空间，因此也具有相同的解耦能力。
  * 我们直接取 $\tilde{Q}$ 作为最终的滤波器。所以，从概念上讲 $Q_3(s)$ 就是那个“修正因子” $M(s)^{-1}$。
* **动态配置**：互质分解具有一定的自由度，我们可以利用这个自由度来指定 $M(s)$ 的零点，从而任意配置最终滤波器 $\tilde{Q}(s)$ 的稳定极点，实现期望的动态响应（如响应速度、阻尼等）。

------

## **总结**

Procedure EFD 的数学逻辑如同一位工匠雕刻作品：

1. **$Q_1$ (获取原料)**：通过**左零空间**计算，从原始系统中“切”出一块包含了所有故障信息、但排除了所有干扰的“原石” $Q_1$。
2. **$Q_2$ (精雕细琢)**：通过解决**最小覆盖问题**，用最经济的刀法（低阶组合）从原石中雕刻出一个最简洁、但依然保留了关键特征（故障敏感性）的雏形 $Q_2 Q_1$。
3. **$Q_3$ (抛光上漆)**：通过**互质分解**，对雏形进行“抛光打磨”，修复其不稳定的瑕疵，并赋予其期望的动态光泽（极点配置），最终得到完美成品 $\tilde{Q}$。

这个三步法将一个混合的设计难题，分解为纯粹的**代数问题 (Step 1)**、**组合优化问题 (Step 2)** 和**系统镇定问题 (Step 3)**，每一步都有成熟的数值工具可以解决，从而保证了算法的鲁棒性和通用性。









# 得到矩阵左零空间的数学原理

左零空间基（Left Nullspace Basis）的计算是故障检测中最核心的数学操作，它的目标是找到一个矩阵（或变换）$N_L(s)$，使得它与给定的系统矩阵相乘后结果为零。

对于一个传递函数矩阵 $G(s) = [G_u(s) \quad G_d(s)]$，寻找其左零空间基 $N_L(s)$ 满足：
 $N_L(s) [G_u(s) \quad G_d(s)] = 0$

这个问题的解决通常不是在传递函数域直接求解（因为涉及多项式分数的复杂运算），而是转化为**状态空间（State-Space）域**的矩阵运算来求解。

------

## **1. 问题的转化：从传递函数到状态空间**

假设系统 $[G_u(s) \quad G_d(s)]$ 的状态空间实现为：
 $\begin{aligned} \dot{x}(t) &= Ax(t) + Bu(t) \\ y(t) &= Cx(t) + Du(t) \end{aligned}$
 其中 $B$ 和 $D$ 是将 $u$ 和 $d$ 对应的矩阵拼接起来的结果。

我们的传递函数矩阵是：
 $G(s) = C(sI - A)^{-1}B + D$

要找一个滤波器 $Q(s)$ 使得 $Q(s)G(s) = 0$，这等价于构建一个新的动态系统（滤波器），其输入是 $y$，使得对于任何 $u$ 产生的 $y$，滤波器的输出恒为零。

------

## **2. 数学原理：系统矩阵束 (System Matrix Pencil)**

解决这个问题的标准数学工具是**系统矩阵束（Rosenbrock System Matrix）**。我们将系统的动态方程写成矩阵形式：
 $\begin{bmatrix} sI - A & -B \\ C & D \end{bmatrix} \begin{bmatrix} x(s) \\ u(s) \end{bmatrix} = \begin{bmatrix} 0 \\ y(s) \end{bmatrix}$

要寻找使得输出 $y$ 对输入 $u$ 解耦的变换，实际上就是在寻找这个大矩阵的**左零空间**。
 我们需要找到向量（或多项式向量）$[v(s) \quad w(s)]$，使得：
 $[v(s) \quad w(s)] \begin{bmatrix} sI - A & -B \\ C & D \end{bmatrix} = 0$

如果找到了这样的 $[v(s) \quad w(s)]$，展开上式得到：
 $v(s)(sI - A) + w(s)C = 0$
 $-v(s)B + w(s)D = 0$

此时，如果我们构建一个滤波器 $Q(s)$，其本质上就是利用 $w(s)$ 来消除系统的动态。数学推导显示，$w(s)$ 正是传递函数矩阵 $G(s)$ 的左零空间基 $N_L(s)$ 的一部分（或者说直接相关）。

**实际上，更精确的算法是基于“系统逆”或“观测器”的概念。**

------

## **3. 几何子空间法（Geometric Approach）**

在状态空间中，消除干扰问题可以转化为几何问题：寻找一个子空间，该子空间包含在观测空间中，且与控制/干扰输入空间正交。

最常用的算法（也是 `glnull` 函数通常采用的方法）是基于 **(A, B)-不变子空间** 或 **不可观测子空间** 的计算。

**简单情形（无直通项 D=0）**：
 如果 $D=0$，干扰只通过状态 $x$ 影响 $y$。

1. 我们想构造一个残差 $r = Ly$，使得 $r$ 不受 $u$ 影响。
2. 这意味着 $LC(sI-A)^{-1}B = 0$。
3. 这等价于寻找观测矩阵 $C$ 的一个线性组合，使得它对可控子空间 $\mathcal{R}(B)$ 正交。或者更广泛地，寻找一个观测器增益 $K$ 和输出矩阵 $H$，使得观测器误差动态完全解耦。

**通用情形（任意系统）—— 压缩形式 (Compression)**

对于一般情况（$D \neq 0$），算法步骤如下：

1. **压缩 D 矩阵**：
    对 $D$ 进行奇异值分解 (SVD) 或 QR 分解，找到一个正交矩阵 $U$，使得：
    $U D = \begin{bmatrix} D_1 \\ 0 \end{bmatrix}$
    其中 $D_1$ 是满行秩的。这把输出 $y$ 分成了两部分：一部分受 $u$ 直接影响，另一部分不受 $u$ 直接影响。
2. **坐标变换与重构**：
    利用这个变换，我们可以把原系统转化为一个新的形式，其中一部分输出方程不再包含直接输入项 $u$。
3. **递归降阶（Silverman 算法 / 结构算法）**：
    如果还有状态通过 $x$ 影响输出，我们对状态方程进行微分（相当于在 s 域乘以 s），再次尝试消除 $u$。这个过程是递归的，本质上是在计算系统的**逆系统 (Inverse System)** 的零动态。
   * 左零空间基其实就是系统**左逆 (Left Inverse)** 的存在性问题。
   * 如果系统是左可逆的，那么其左零空间就是空的（只有零解）。
   * 如果系统不是左可逆的（即输入多于输出，或者存在冗余），那么剩下的那些“多余”的自由度就构成了左零空间。

------

## **4. 这里的核心算法：Varga 的方法 (Based on Matrix Pencils)**

Varga 在书中采用的方法（以及 `FDITOOLS` 的实现）直接处理矩阵束 $P(s) = \begin{bmatrix} sI - A & -B \ C & D \end{bmatrix}$。

**算法逻辑**：

1. 寻找 $P(s)$ 的左零空间基 $[N_x(s) \quad N_y(s)]$。
    这可以通过 **Kronecker 标准型 (Kronecker Canonical Form)** 的计算，或者更数值稳定的 **阶梯型 (Staircase Form)** 算法（如 Beelen 算法）来实现。
2. 这些算法会通过一系列正交变换（SVD/QR），把矩阵束 $P(s)$ 转化为阶梯形状，从而显式地分离出其奇异部分（Singular Part）。
3. 奇异部分的左零向量，直接给出了我们需要的 $N_L(s)$。
   * 具体来说，$N_L(s) = N_y(s)$ 就是 $G(s)$ 的左零空间基。

**为什么这样算好？**

* **数值稳定性**：完全基于正交变换（Unitary Transformations），避免了求逆带来的数值误差。
* **多项式基**：该方法可以直接给出 $N_L(s)$ 的最小多项式基形式，这意味着我们可以直接控制解的阶数，保证找到的是阶数最低的解（对应 Minimal Polynomial Basis）。

## **总结**

得到 $[G_u ; G_d]$ 左零空间基的数学原理，本质上是：
 **在系统的广义状态空间矩阵束 $\begin{bmatrix} sI-A & -B \ C & D \end{bmatrix}$ 中，寻找一组线性依赖关系，使得这些关系对任何状态 $x$ 和输入 $u$ 都恒成立。**

这组关系定义了一个新的输出（残差），它只取决于系统的内部结构冗余，而与外部输入无关。这就是解耦的物理本质。





# 得到最小阶滤波器的降阶原理

在 Procedure EFD 中，我们第一步得到的 $Q_1(s)$ 往往阶数很高，且拥有多个输出通道。$Q_2(s)$ 的作用就是从这些高阶、多通道的信号中，精选出一个**单通道的线性组合**，使得最终滤波器 $Q(s) = Q_2(s) Q_1(s)$ 的**物理阶数（McMillan 阶）最小**，同时依然能检测到故障。

这个过程在数学上被称为**最小覆盖问题 (Minimal Cover Problem)** 的一种变体。下面我们从**最小多项式基**的角度来深入剖析其原理。

------

## **1. 预备知识：多项式矩阵与行阶数**

$Q_1(s)$ 可以被视为一个**多项式矩阵**（在去除分母公因式后）。设 $Q_1(s)$ 有 $k$ 行（即 $k$ 个基向量）：
 $Q_1(s) = \begin{bmatrix} q_1(s) \\ q_2(s) \\ \vdots \\ q_k(s) \end{bmatrix}$
 其中每一行 $q_i(s)$ 都是一个行向量，代表一个独立的解耦方向。

* 每个 $q_i(s)$ 都有一个**行阶数 (Row Degree)**，记为 $d_i$。它表示这一行中 s 的最高次幂。
* **关键性质**：如果我们用正交变换（如 `glnull` 中的算法）计算 $Q_1$，我们可以保证它是一个**行真 (Row Proper)** 或 **最小多项式基**。这意味着这些行向量是线性独立的，且它们的阶数之和是所有可能的基中最小的。我们把它们按阶数从小到大排序：$d_1 \le d_2 \le \dots \le d_k$。

------

## **2. 寻找 $Q_2(s)$：构造线性组合**

我们要找的 $Q_2(s)$ 是一个 $1 \times k$ 的向量：
 $Q_2(s) = [\alpha_1(s) \quad \alpha_2(s) \quad \dots \quad \alpha_k(s)]$
 这里的系数 $\alpha_i(s)$ 也是多项式。
 最终滤波器是：
 $Q_{new}(s) = \sum_{i=1}^{k} \alpha_i(s) q_i(s)$

**目标**：

1. **非零响应**：$Q_{new}(s) R_f(s) \neq 0$。即不能把故障也消除了。
2. **最小阶数**：$Q_{new}(s)$ 的阶数 $\deg(Q_{new})$ 最小。

------

## **3. 降阶搜索策略 (Order Search Strategy)**

如何找到使阶数最小的组合？这就变成了一个搜索问题。

**第一层搜索：尝试使用低阶基向量**
 由于 $q_i(s)$ 已经按阶数 $d_i$ 排序，如果只用 $q_1(s)$（阶数最低）就能检测到故障，那当然最好。
 如果不行，再考虑用 $q_1$ 和 $q_2$ 组合...
 设我们要找的 $Q_{new}$ 的目标阶数为 $\nu$。

**第二层搜索：设计系数 $\alpha_i(s)$**
 对于选定的基向量子集，我们要确定系数 $\alpha_i(s)$。为了保持总阶数不超过 $\nu$，系数 $\alpha_i(s)$ 的阶数受到限制：
 $\deg(\alpha_i(s)) + d_i \le \nu$
 这意味着：

* 对于阶数很低（$d_i \ll \nu$）的基向量 $q_i$，其系数 $\alpha_i(s)$ 可以是高阶多项式。
* 对于阶数很高（$d_i \approx \nu$）的基向量，其系数只能是常数。
* 对于阶数超过 $\nu$ 的基向量，其系数必须为 0。

**具体的数学构建（Nullspace Again）**：
 这个问题再次转化为求解一个线性方程组的零空间问题。
 我们将所有可能的系数展开，写成一个巨大的线性方程组矩阵（Sylvester 矩阵形式）。我们要在这个矩阵的零空间中找解（如果要求 $Q_{new} R_f = 0$），或者在零空间之外找解（我们的情况，要求 $\neq 0$）。

在 Procedure EFD 中，实际上我们是在解一个**对偶问题**：
 寻找一个组合，使得它对故障 $R_f$ 的投影**不是零**。这通常比找零容易得多——几乎任何随机组合都满足“非零”条件。
 **真正的挑战是**：在所有满足“非零”的组合中，哪一个阶数最小？

Varga 的算法采用了**结构化搜索**：

1. **Order 0 (常数组合)**：
    尝试 $\alpha_i(s)$ 为常数。此时 $Q_{new}$ 的阶数上限就是 $\max(d_i)$（对于 $\alpha_i \neq 0$ 的 $i$）。
    为了让总阶数最小，我们应该只选那些 $d_i$ 最小的行。
    检查：只用 $d_1$ 行能否检测故障？如果能，结束。
    如果不能，尝试用 $d_1, d_2$ 行的常数组合...
2. **Order > 0 (多项式组合)**：
    有时候，简单的相加无法消除高阶项。我们需要用多项式系数来“对消”高阶项，从而降低总阶数。
   * 例如：$q_1(s) = s+1$, $q_2(s) = s^2$。直接加是 $s^2+s+1$ (2阶)。
   * 但如果 $q_1(s) = s^2+s$, $q_2(s) = s^2$。我们可以用 $1 \cdot q_1 - 1 \cdot q_2 = s$ (1阶)。
      这就是 `glmcover1` 算法做的事情：它在多项式空间中寻找系数，使得高阶项相互抵消，从而暴露出低阶的“核”。

------

## **4. 直观理解**

把 $Q_1$ 的每一行想象成不同长度的木板（长度代表阶数 $d_i$）。

* $q_1$: 1米长
* $q_2$: 2米长
* $q_3$: 5米长

你想造一座桥（滤波器）跨过河流（检测故障）。

1. 首先试 $q_1$（1米）：太短，够不到河对岸（无法检测某些故障，或者 $R_f$ 在这个方向投影为0）。
2. 再试 $q_2$（2米）：够到了！那这一步的最优解就是用 $q_2$，阶数是 2。
3. 但等等，如果 $q_1$ 和 $q_2$ 组合一下呢？比如 $q_{new} = q_2 - s \cdot q_1$？
   * 如果 $q_2$ 的高次项能被 $s \cdot q_1$ 抵消掉，剩下的残余部分可能只有 0.5 米长（阶数降低）。
   * 但这里我们要求的是“能检测故障”，通常不需要抵消到 0，而是只要存在就行。但在**最小阶观测器**设计中，我们不仅要存在，还要让观测器的动态最简单。

在故障检测中，**“降阶”更多是通过选择来实现的**，而不是通过复杂的对消。
 因为 $Q_1$ 已经是最小基了，它的行之间通常没有多余的线性相关性可以用来做大规模的对消降阶。
 **所以，$Q_2$ 的主要工作通常是：在 $Q_1$ 的众多行向量中，挑选出那些“阶数最低”且“对故障敏感”的行，把它们保留下来，扔掉那些阶数高或者对故障没反应的行。**

这就是为什么代码里会有 `efdbasesel`（基向量选择）这个函数，它就是在做这个“挑选”工作。

## **总结**

$Q_2(s)$ 的降阶原理是：
 利用 $Q_1(s)$ 提供的多个解耦方向（自由度），优先选择那些**动态最简单（阶数低）\**的方向。如果单个方向不够（无法覆盖所有故障），就尝试用几个低阶方向的\**最简线性组合**来合成一个新的方向。算法保证了在所有能完成任务的组合中，选出的那个是数学上最简单的。

# **Procedure EFD (Exact Fault Detection) 算法详解**

书中的 **Procedure EFD** 是解决 **精确故障检测问题 (EFDP)** 的核心算法，也是更复杂的 EFDI（故障检测与隔离）算法的基础组件。它的目标是设计一个滤波器 $Q$，使得产生的残差 $r$ 完全解耦干扰（$Ru=0, Rd=0$），同时对故障敏感（$Rf \neq 0$），并具有尽可能低的阶数（Least Order）。

以下是对该算法的详细数学解释和步骤拆解：

------

## **核心思想**

Procedure EFD 依然基于 **零空间方法 (Nullspace Method)**，但它引入了更精细的后续步骤来优化滤波器的阶数和动态特性。
 整个过程基于滤波器的**乘积分解形式**：
 $Q(s) = Q_3(s) Q_2(s) Q_1(s)$

* $Q_1(s)$：**全局解耦器**。负责消除所有干扰。
* $Q_2(s)$：**降阶与检测优化器**。负责在 $Q_1$ 的基础上寻找阶数最低的线性组合，同时保证对故障的敏感性。
* $Q_3(s)$：**动态配置器**。负责赋予滤波器稳定的极点（Dynamics Assignment）。

------

## **详细步骤 (Step-by-Step)**

## **输入**

系统传递函数矩阵 $G(s) = [G_u(s) ; G_d(s) ; G_f(s)]$。

## **Step 1: 初始解耦 (Initial Decoupling)**

计算系统关于干扰的左零空间基，消除 $u$ 和 $d$ 的影响。

1. 构造干扰矩阵 $G_{dist} = [G_u(s) ; G_d(s) ; I_{mu} ; 0]$（最后的 $I$ 和 $0$ 对应输入通道的直接馈通部分，视具体实现而定，核心是 $G_u$ 和 $G_d$）。
2. **计算 $Q_1(s)$**：计算 $G_{dist}$ 的最小左零空间基 $N_L(s)$，使得 $N_L [G_u ; G_d] = 0$。
   * 令 $Q = Q_1 = N_L$。
3. **计算剩余影响**：计算消除干扰后，故障和噪声对残差的影响矩阵：
    $R_f = Q_1 G_f, \quad R_w = Q_1 G_w$
4. **可解性检查**：检查 $R_f$ 的每一列 $j$。如果存在某列全是 0（$R_{fj} = 0$），说明该故障与干扰完全不可分，问题无解，退出。

## **Step 2: 最小阶优化 (Least Order Synthesis)**

这一步是 Procedure EFD 的精华。$Q_1$ 通常是一个矩阵（多输出），我们需要找到一个最佳的**标量输出**组合 $Q_2$，使得最终滤波器阶数最低。

1. **寻找 $Q_2$**：我们需要找一个行向量 $Q_2(s)$，使得组合后的滤波器 $Q_{new} = Q_2 Q_1$ 的 McMillan 阶数最小，且满足故障检测条件 $Q_2 R_f \neq 0$。
2. **具体实现 (Polynomial Method)**：
   * 设 $Q_1$ 的行向量为 $v_1, \dots, v_k$，它们的阶数分别为 $n_1 \le n_2 \le \dots \le n_k$。
   * 我们尝试构建线性组合：$Q_2 = [\alpha_1(s) \dots \alpha_k(s)]$。
   * **搜索策略**：从最低阶开始尝试。首先尝试常数线性组合。如果常数组合能保证 $Q_2 R_f \neq 0$，则得到零阶 $Q_2$。如果不行，则尝试一阶多项式组合，依此类推。
   * 书中 **Remark 5.4** 提到了一种简化方法：利用结构矩阵 $S_{R_f}$。如果前 $i$ 行的线性组合足以覆盖所有非零列，就只用前 $i$ 行，这样能保证阶数不超过 $n_i$。
3. **更新**：
    $Q \leftarrow Q_2 Q, \quad R_f \leftarrow Q_2 R_f, \quad R_w \leftarrow Q_2 R_w$
    此时 $Q$ 变成了单输出滤波器（Scalar Output Filter）。

## **Step 3: 稳定性与动态配置 (Stability and Dynamics Assignment)**

前两步得到的滤波器 $Q$ 可能是物理不可实现的（Improper）或者不稳定的。这一步用来修复这些问题。

1. **寻找 $Q_3$**：我们需要找一个标量传递函数 $Q_3(s)$（通常取为 $M(s)^{-1}$ 的形式），使得最终的滤波器 $Q_{final} = Q_3 Q$ 是稳定且正规（Proper）的。
2. **具体实现 (Coprime Factorization)**：
   * 对目前的残差生成器 $[Q ; R_f ; R_w]$ 进行**稳定左互质分解 (Stable Left Coprime Factorization, LCF)**：
      $[Q \; R_f \; R_w] = M^{-1} [\tilde{Q} \; \tilde{R}_f \; \tilde{R}_w]$
      其中 $M, \tilde{Q}, \tilde{R}_f, \tilde{R}_w$ 都是稳定且正规的传递函数。
   * 令 $Q_3 = M^{-1}$。但实际上我们不需要显式求逆，直接取分解得到的分子部分 $\tilde{Q}$ 作为最终滤波器即可。
   * 这样，最终滤波器的极点即为 $M(s)$ 的零点，我们可以通过极点配置技术（Pole Placement）在分解过程中任意指定这些极点（即滤波器的响应速度）。
3. **最终更新**：
    $Q \leftarrow \tilde{Q}, \quad R_f \leftarrow \tilde{R}_f, \quad R_w \leftarrow \tilde{R}_w$

------

## **总结**

**Procedure EFD** 的核心逻辑链条是：

1. **先解耦** ($Q_1$)：不管三七二十一，先把干扰消掉，得到一个“虽然能用但可能很复杂”的滤波器基底。
2. **再降阶** ($Q_2$)：在基底中挑挑选选，找出一个最简单的组合，既能检测故障，阶数又最低。
3. **后镇定** ($Q_3$)：把这个最简单的组合“打磨”一下，让它稳定、因果可实现，并具有我们想要的动态响应特性。

最终输出的 $Q$ 就是一个**单输出、最小阶、稳定、因果**的故障检测滤波器。

# 最小阶综合函数：glmcover1

`glmcover1` 是一个在故障诊断（和控制理论）中极其重要的底层工具函数，它解决了 **Type 1 最小动态覆盖问题 (Minimum Dynamic Cover Problem of Type 1)**。

在 `efdsyn` 中，这个函数被用来实现 **最小阶综合 (Least Order Synthesis)**，即找到一个使得滤波器阶数最小的线性组合。

以下是对该函数及其数学原理的详细解释。

------

## **1. 核心功能与数学问题**

**问题描述**：
 给定两个系统 $SYS_1(s)$ 和 $SYS_2(s)$（通常 $SYS_2$ 就是我们要找的 $Q_2$，或者与之相关），我们要寻找一个 **修正系统 (Correction System)** $SYS_Y(s)$（即反馈增益 $F$ 的动态形式）和一个 **结果系统** $SYS_X(s)$，使得：
 $SYS_X(s) = SYS_1(s) + SYS_Y(s) SYS_2(s)$
 并且 $SYS_X(s)$ 的 **McMillan 阶数最小**。

**物理意义**：
 在故障检测中，这相当于：

* $SYS_1$ 是当前的残差生成器 $Q_{old}$。
* $SYS_2$ 是我们可以利用的自由度（例如观测器增益对应的动态）。
* 我们要通过 $SYS_Y$ 调整 $SYS_1$，得到新的滤波器 $SYS_X$，使得 $SYS_X$ 的阶数尽可能低（去除不可观测/不可控的状态）。

**对偶性**：
 代码中可以看到，`glmcover1` 实际上是调用了 `grmcover1`（右最小动态覆盖）：

```
matlab
[sysx,info] = grmcover1(sys1.',sys2.',tol);
```

这说明 **GLMCOVER1 (Left)** 是 **GRMCOVER1 (Right)** 的对偶问题。

* **左覆盖 (Left Cover)**：$X = G_1 + Y G_2$ （寻找左乘因子 $Y$）
* **右覆盖 (Right Cover)**：$X = G_1 + G_2 Y$ （寻找右乘因子 $Y$）
   通过转置（`.`），我们将左覆盖问题转化为右覆盖问题来求解。

------

## **2. 算法原理：几何子空间与输出注入**

`glmcover1` 实现的是 Varga 在  中提出的算法。其核心是基于 **几何子空间 (Geometric Subspaces)** 和 **输出注入 (Output Injection)**。Varga-2017-Solving-Fault-Diagnosis-Problems-Linear-Synthesis.pdf[mathworks](https://www.mathworks.com/matlabcentral/fileexchange/91400-fditools)

## **Step 1: 状态空间拼接**

首先将 $SYS_1$ 和 $SYS_2$ 拼成一个大的描述符系统（或者标准系统）：
 $\begin{aligned} \dot{x} &= Ax + Bu \\ y &= \begin{bmatrix} C_1 \\ C_2 \end{bmatrix} x + \begin{bmatrix} D_1 \\ D_2 \end{bmatrix} u \end{aligned}$
 其中 $C_1$ 对应 $SYS_1$ 的输出，$C_2$ 对应 $SYS_2$ 的输出。

## **Step 2: 输出注入 (Output Injection)**

我们要找一个矩阵 $F$（输出注入增益），将 $C_2$ 的输出反馈回系统状态：
 $\dot{x} = (A + FC_2)x + (B + FD_2)u$
 使得新的系统 $(A+FC_2, C_1)$ 具有**最大数量的不可观测特征值**。

**为什么要最大化不可观测性？**

* 如果我们让某些状态变得不可观测，那么在最小实现（Minimal Realization）中，这些状态就会被消除掉。
* 消除的状态越多，最终系统 $SYS_X$ 的阶数就越低。
* 这就是“降阶”的本质：通过注入 $F$，让尽可能多的系统动态对输出 $C_1$ “隐身”。

## **Step 3: 阶梯形计算 (Staircase Form)**

为了找到这个最优的 $F$，算法使用了 **可观测性阶梯形 (Observability Staircase Form)**。
 通过一系列正交变换，将系统矩阵 $(A, C_2)$ 转化为阶梯形式。在这个形式下，我们可以显式地看到哪些状态是可以通过选择适当的 $F$ 来使其变得不可观测的。

------

## **3. 代码逐行解析**

```
matlab
function [sysx,info,sysy] = glmcover1(sys1,sys2,tol)
```

* **输入**：
  * `sys1` ($G_1$): 目标系统。
  * `sys2` ($G_2$): 用于覆盖的源系统。
  * `tol`: 容差。

```
matlab% 输入检查
if nargin < 3, tol = 0; end
if ~isa(sys1,'ss'), ... end
% 关键：转置调用 grmcover1
if nargout <= 2
   [sysx,info] = grmcover1(sys1.',sys2.',tol);
elseif nargout == 3
    [sysx,info,sysy] = grmcover1(sys1.',sys2.',tol);
end
```

* **转置**：因为 Varga 的核心算法是针对右覆盖问题（Right Cover, $X = G_1 + G_2 Y$）编写的 `grmcover1`。根据对偶原理，左覆盖问题 $X = G_1 + Y G_2$ 可以通过转置所有矩阵，解右覆盖问题，然后再转置回来得到。

```
matlab% 转置回来，恢复原系统的方向
sysx = xperm(sysx,order(sysx):-1:1).';
if nargout == 3
   sysy = xperm(sysy,order(sysy):-1:1).';
end
% 翻转结构指数信息
info.stdim = flip(info.stdim); 
```

* **后处理**：
  * `xperm`: 对状态进行重排序（Permutation）。这是因为转置操作会改变阶梯型的顺序（从上到下变从下到上），需要翻转回来。
  * `sysx.'`: 将结果转置回左覆盖的形式。

------

## **4. 在 EFDSYN 中的作用**

在 `efdsyn` 的 Step 2（最小阶综合）中：

* `sys1` 对应当前的滤波器 $Q$（或其一部分）。
* `sys2` 对应 $Q$ 的左零空间基的一部分（即我们拥有的设计自由度）。
* 调用 `glmcover1` 寻找一个 $F$（在这里表现为线性组合系数），使得组合后的新系统（即新滤波器）阶数最小。

**直观例子**：
 假设当前的滤波器 $Q$ 阶数为 5。我们发现如果加上 $0.5 \times (\text{某个基向量})$，可以把其中 3 个状态变得不可观测（即这些状态对残差没有贡献了）。
 那么 `glmcover1` 就会找到这个系数 0.5，并返回消除这 3 个状态后的新滤波器（阶数变为 2）。

## **总结**

`glmcover1` 是一个高级的**模型降阶工具**。

* 它不是盲目地截断状态，而是通过利用系统已有的冗余（由 $sys2$ 提供），**主动地构造**不可观测性。
* 它是 **Procedure EFD** 实现“最小阶（Least Order）”特性的核心引擎。没有它，生成的故障检测滤波器可能会非常复杂，难以工程实现。
