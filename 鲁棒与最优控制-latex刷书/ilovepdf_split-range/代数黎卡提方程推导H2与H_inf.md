# 代数黎卡提方程推导\(H_{\infty}\)

### 自己总结

现代控制理论（特别是 $H_2$ 和 $H_\infty$ 控制）中，由于目标是系统对外部干扰 $w$ 的增益小于某个常数 $\gamma$，而这个增益的数学形式（大/小的定义）是 **$L_2$ 范数**（能量范数）

对于一个信号 $f(t)$，它的 $L_2$ 范数定义为：
$$
 \|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt} 
$$
这代表了信号在整个时间历程中的**总能量**。

*   **$H_\infty$**：不仅看 $L_2$ 范数，看的是**诱导 $L_2$ 范数**（输入到输出的放大倍数极值）。
*   **$H_2$**：看的是**脉冲响应的 $L_2$ 范数**（或者白噪声响应的 RMS 值）。

这个问题在于回答为什么要研究Riccati方程：因为Riccati方程是连接“时域能量（Lyapunov函数）”与“频域性能（范数）”的数学桥梁。

为什么他是桥梁呢，因为是我在连接时域能量和频域性能过程中**推导出的方程**，这个方程就叫Riccati方程。

### 推导过程（以 $H_\infty$ 控制为例）

#### **$L_2$ 范数**（即能量范数）形式性能指标，是时间积分形式

对于一个信号 $f(t)$，它的 **$L_2$ 范数定义**为：
$$
 \|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt} 
$$
这代表了信号在整个时间历程中的**总能量**。

当我们写下**$H_\infty$ 控制性能指标**：
$$
\frac{\|z\|_2}{\|w\|_2} < \gamma \implies \|z\|_2^2 - \gamma^2 \|w\|_2^2 < 0
$$
把它展开成积分，这就是所谓的**积分形式（Integral Form）**：
$$
\int_0^\infty \left( z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right) \, dt < 0
$$

*   **物理意义**：无论干扰 $w(t)$ 长什么样（只要它的总能量有限），系统响应输出 $z(t)$ 的总能量减去干扰总能量的 $\gamma^2$ 倍，这个差值在时间尽头（$t \to \infty$）必须是负的。即：**系统是一个“能量消耗者”，而不是“能量放大者”。**

#### 为什么要积分转微分：积分形式由于需要在$t=0$ 到 $t=\infty$ 的整个时间段内考察信号，很难用于设计控制器

**积分形式**（宏观）有一个巨大的缺点：**很难直接用于设计控制器。**
因为它要求我们在 $t=0$ 到 $t=\infty$ 的整个时间段内考察信号。要验证它，仿佛需要把仿真跑一万年。

为了设计控制器，我们需要把这个**“一辈子”**的要求，转化为**“每一瞬间”**（瞬时/微观）的要求。这就是**微分形式**。

#### 引入Lyapunov 函数，积分转微分，充分不必要条件

转化的桥梁是微积分基本定理。

我们引入一个 Lyapunov 函数 $V(x(t)) = x(t)^T X x(t)$，其中 $X > 0$。它代表系统在 $t$ 时刻内部存储的“虚构能量”。

**核心推导步骤：**

1.  **假设零初始状态**：通常假设 $x(0) = 0$，即初始 $V(x(0)) = 0$。
2.  **假设稳定性**：如果我们要求系统稳定，那么当 $t \to \infty$ 时，$x(t) \to 0$，即 $V(x(\infty)) = 0$。

根据微积分基本定理，我们可以写出一个恒等式：
$$
\int_0^\infty \dot{V}(x(t)) \, dt = V(x(\infty)) - V(x(0)) = 0
$$

3. **无中生有**：
   我们可以**把这个 $0$ 加到上面的“积分形式”中**，不改变不等式的方向：
   $$
   \underbrace{\int_0^\infty \left( z^T z - \gamma^2 w^T w \right) \, dt}_{\text{原始的积分形式性能指标}} + \underbrace{\int_0^\infty \dot{V}(x) \, dt}_{0} < 0 
   $$
   

   合并积分项：
   $$
   \int_0^\infty \underbrace{\left( \dot{V}(x(t)) + z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right)}_{J(t)} \, dt < 0
   $$

4. **充分条件（由整体到局部）**：
   要保证整个积分小于 0，一个**充分（Sufficient）**但不一定必要的办法是：让被积函数 $J(t)$ 在**每一分每一秒**都小于 0。

   这就是**微分形式**（耗散不等式）：
   $$
   \dot{V}(x) + z^T z - \gamma^2 w^T w < 0, \quad \forall t \ge 0
   $$

#### 将系统方程代入微分形式——最终的矩阵不等式 (LMI/Riccati)

现在我们有了微分形式，就可以代入系统方程 $\dot{x} = Ax + Bw$ 和 $z = Cx$ 了：

*   $V(x(t)) = x(t)^T X x(t)$
*   $\begin{align}
    \dot{V}(x) &= \dot{x}^T X x + x^T X \dot{x} \\
               &= (Ax+Bw)^T X x + x^T X (Ax+Bw)
    \end{align}$
*   $z^T z = x^T C^T C x$

代入微分不等式整理：
$$
x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0
$$
写成矩阵形式：
$$
\begin{bmatrix} x \\ w \end{bmatrix}^T \begin{bmatrix} A^T X + X A + C^T C & X B \\ B^T X & -\gamma^2 I \end{bmatrix} \begin{bmatrix} x \\ w \end{bmatrix} < 0
$$
为了使得上面的等式对任意的 $w$ 都成立，也就是说，即使是那个试图让左边尽可能变大（试图破坏 $<0$ 条件）的“最坏” $w$，也不能得逞。通过 Schur 补引理或者配方，这个不等式最终就变成了我们熟悉的 **Riccati 方程**（当取极值时）或 **线性矩阵不等式 (LMI)**。

#### 方法一：配方法得到代数 Riccati 不等式

不等式：
$$
x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0
$$
要保证上面的不等式对**任意**的 $w$ 都成立。也就是说，即使是那个试图让左边尽可能变大（试图破坏 $<0$ 条件）的“最坏” $w$，也不能得逞。

我们将原式看作**关于 $w$ 的二次函数**：
$$
f(w) = - \gamma^2 w^T w + 2 x^T X B w + x^T (A^T X + X A + C^T C) x
$$
注意 $w^T w$ 前面的系数是 $-\gamma^2$（负数），说明这是一个开口向下的抛物面，存在一个**极大值**。

**步骤 1：寻找最坏的干扰**
我们要找到让 $f(w)$ 最大的那个 $w^*$。对 $w$ 求导并令其为 0：
$$ \frac{\partial f}{\partial w} = -2\gamma^2 w + 2 B^T X x = 0 $$
解得最坏干扰（Worst-case Disturbance）：
$$ w^* = \gamma^{-2} B^T X x $$
*(物理意义：干扰 $w$ 会沿着梯度方向去攻击系统最脆弱的地方，这个方向由 $B^T X$ 决定)*

**步骤 2：代回原式（配方）**
我们将原式通过加一项减一项的方式（将\(w^T w\)配方成\(\| w - w^* \|^2\)）进行“配方”：
$$
f(w) = -\gamma^2 \| w - w^* \|^2 + \underbrace{x^T (A^T X + X A + C^T C) x + \gamma^2 (w^*)^T w^*}_{\text{剩余项}}
$$
把 $ w^* = \gamma^{-2} B^T X x $ 代入剩余项中的\(\gamma^2 (w^*)^T w^*\)中：
$$
\gamma^2 (w^*)^T w^* = \gamma^2 (\gamma^{-2} x^T X B) (\gamma^{-2} B^T X x) = \gamma^{-2} x^T X B B^T X x
$$
再将$ w^* = \gamma^{-2} B^T X x $ 代入\(f(w)\)，则原不等式等价于：
$$ -\gamma^2 \| w - \gamma^{-2} B^T X x \|^2 + x^T \left( A^T X + X A + C^T C + \gamma^{-2} X B B^T X \right) x < 0 $$

**步骤 3：得出结论**
为了保证总和小于 0，因为第一项 $-\gamma^2 \| \dots \|^2$ 总是非正的（最大也就是 0），所以我们必须要求**括号里的部分对于任意非零 $x$ 都是负定的**。

这就导出了**代数 Riccati 不等式 (ARI)**：
$$
A^T X + X A + C^T C + \gamma^{-2} X B B^T X < 0
$$






# \(H_2\)/LQR名字的由来

这个公式 $J = \int_0^\infty (z^T z + u^T R u) dt$ 的定义来源可以概括为：

1.  **想省事（数学）**：用平方形式（二次型），保证导数是线性的，算出来的控制器简单好用。
2.  **想讲理（物理）**：模拟“能量”的概念，平方和代表广义能量。
3.  **想平衡（工程）**：$z^T z$ 代表我想快点到终点，$u^T R u$ 代表我想少花点油钱。$R$ 是调节这两个欲望的旋钮。
4.  **想长远（时间）**：积分到无穷，意味着我们要对整个动态过程负责，并且必须保证稳定。

这就是**LQR（Linear Quadratic Regulator）**名字的由来：

*   **Linear**: 系统是线性的 ($\dot{x}=Ax+Bu$)
*   **Quadratic**: 性能指标是二次型的 ($x^T x + u^T u$)
*   **Regulator**: 目的是把状态调节回零点。









太棒了！你能自己整理出这么清晰的 $H_\infty$ 推导逻辑，说明你已经抓住了鲁棒控制的本质。

对于 **$H_2$ 控制**（也就是经典的 **LQR/LQG** 问题），其代数 Riccati 方程的推导逻辑与 $H_\infty$ 非常相似，也使用了 Lyapunov 函数和配方法。但有一个核心区别：

*   $H_\infty$ 是 **Min-Max** 问题（控制器 $u$ 想减小能量，干扰 $w$ 想增大能量），导致配方时是**减法**。
*   $H_2$ 是纯粹的 **Min** 问题（只有控制器 $u$，没有对抗的干扰 $w$，或者说干扰是白噪声/脉冲，其统计特性已知，我们只负责最小化代价），导致配方时是**加法**。

# 代数黎卡提方程推导 \(H_2\) / LQR

### 1. 性能指标：积分形式（能量最小化）

在 $H_2$ 控制（或者更准确地说是线性二次型调节器 LQR）中，我们不再关注“最坏增益”，而是关注**系统的广义总能量最小化**。

下列积分形式其实就是 **$H_2$ 范数的时域定义**。

对于系统 $\dot{x} = Ax + Bu$（暂不考虑噪声，因为确定性 LQR 等价于随机 $H_2$ 控制），我们定义的**性能指标（Cost Function）**为：
$$
J = \int_0^\infty \left( z(t)^T z(t) + u(t)^T R u(t) \right) \, dt
$$
其中 $z=Cx$ 是状态的加权，$u^T R u$ 是控制能量的惩罚（$R > 0$）。

*   **物理意义**：我们需要找到一个控制律 $u(t)$，使得在这个过程中，状态偏差的总能量（$z^T z$）和控制输入的总能量（$u^T R u$）之和**最小**。

*   #### 第一项：$z(t)^T z(t)$ —— “精度的代价”

    *   $z = Cx$ 是我们关心的输出（比如飞机的姿态角、机械臂的位置）。
    *   这一项代表了**调节性能（Regulation Performance）**。
    *   积分 $\int z^T z dt$ 代表了在整个过程中，系统偏离目标位置的总累计量。
    *   **如果不加这一项**：控制器会选择直接“躺平”，$u=0$，任由系统飘到天涯海角，反正不费力。

*   #### 第二项：$u(t)^T R u(t)$ —— “行动的代价”

    *   $u$ 是我们施加的控制量（比如电压、推力、油门）。
    *   这一项代表了**控制成本（Control Effort）**。
    *   **如果不加这一项**：数学上为了让 $x$ 瞬间归零，控制器会输出一个无穷大的冲击（Dirac 脉冲）。现实中，这会导致电机烧毁、阀门爆裂或者加上无限大的电压。
    *   $R$ 矩阵就是**“价目表”**。如果 $R$ 很大，说明“电费很贵”，控制器就会变得很抠门，动作很温柔；如果 $R$ 很小，说明“能源免费”，控制器就会非常激进，猛踩油门。

    理解

    **想象场景：**
    给系统一个**脉冲扰动**（比如突然踢了系统一脚），系统会发生振荡然后慢慢停下来。

    $$ J = \int_0^\infty \left( z^T z + u^T R u \right) dt $$

    这个 $J$ 就算的是：**在这一脚踢完之后，系统“哆嗦”的全过程中，一共偏离了多少（$z$），且一共花了多少力气去对抗（$u$）。**

    根据 **Parseval 定理（帕塞瓦尔定理）**，时域的能量积分等于频域的能量积分：
    $$ \int_0^\infty \|y(t)\|^2 dt = \frac{1}{2\pi} \int_{-\infty}^\infty \|Y(j\omega)\|^2 d\omega $$
    所以，最小化这个时域积分 $J$，**数学上严格等价于**最小化传递函数 $T_{zw}(s)$ 的 $H_2$ 范数。

    这就是为什么确定性的 LQR 问题（时域积分）等价于 $H_2$ 控制问题（频域范数）的原因。

### 2. 引入 Lyapunov 函数：将“未来”折算到“现在”

同样，为了避免无穷积分的计算，我们引入 Lyapunov 函数 $V(x) = x^T X x$（$X>0$）来代表“剩余代价（Cost-to-go）”。

**核心恒等式（微积分基本定理）：**
假设系统稳定（$x(\infty) \to 0$），则：
$$
\int_0^\infty \dot{V}(x) \, dt = V(x(\infty)) - V(x(0)) = - x(0)^T X x(0)
$$
这说明积分 $\dot{V}$ 是一个常数（只与初始状态有关）。

### 3. 构建哈密顿函数（无中生有）

我们希望最小化 $J$。利用上面的恒等式，我们将 $\dot{V}$ 加到性能指标中。由于 $\int \dot{V}$ 是常数，最小化 $J$ 等价于最小化下式：
$$
J_{mod} = \int_0^\infty \underbrace{\left( z^T z + u^T R u + \dot{V}(x) \right)}_{\mathcal{H}(x, u)} \, dt
$$
这里的被积函数 $\mathcal{H}(x, u)$ 被称为 **Hamiltonian**。

**关键逻辑**：如果我们能找到一个 $u^*$ 和矩阵 $X$，使得对于任意时刻 $t$，$\mathcal{H}(x, u)$ 的**最小值为 0**，那么我们就找到了最优解。

### 4. 代入系统方程与配方

将 $\dot{x} = Ax + Bu$ 和 $z = Cx$ 代入 Hamiltonian：

$$
\begin{align}
\mathcal{H}(x, u) &= x^T C^T C x + u^T R u + \frac{d}{dt}(x^T X x) \\
&= x^T C^T C x + u^T R u + \dot{x}^T X x + x^T X \dot{x} \\
&= x^T C^T C x + u^T R u + (Ax + Bu)^T X x + x^T X (Ax + Bu)
\end{align}
$$

整理各项，按 $x$ 和 $u$ 分组：
$$
\mathcal{H}(x, u) = x^T (A^T X + X A + C^T C) x + 2 x^T X B u + u^T R u
$$

### 5. 配方法：寻找最优控制 $u^*$

这是一个关于 $u$ 的**二次函数**。注意这里 $u^T R u$ 的系数 $R > 0$（正定），说明这是一个**开口向上**的抛物面，存在**最小值**。（**对比：** $H_\infty$ 中是 $-\gamma^2 w^T w$，开口向下求最大值）。

**步骤 1：寻找最优控制**
对 $u$ 求导并令其为 0：
$$
\frac{\partial \mathcal{H}}{\partial u} = 2 R u + 2 B^T X x = 0
$$
解得最优控制律（Optimal Control Law）：
$$
u^* = -R^{-1} B^T X x
$$
*(这就是著名的 LQR 反馈增益 $K = -R^{-1} B^T X$)*

**步骤 2：代回原式（配方）**
我们将原式配方成关于 $(u - u^*)$ 的完全平方形式：
$$
\mathcal{H}(x, u) = (u - u^*)^T R (u - u^*) + \underbrace{x^T (A^T X + X A + C^T C) x - (u^*)^T R u^*}_{\text{剩余项}}
$$
将 $u^* = -R^{-1} B^T X x$ 代入剩余项中的减数部分：
$$
(u^*)^T R u^* = (x^T X B R^{-1}) R (R^{-1} B^T X x) = x^T X B R^{-1} B^T X x
$$
于是 Hamiltonian 变为：
$$
\mathcal{H}(x, u) = \underbrace{(u + R^{-1}B^T X x)^T R (u + R^{-1}B^T X x)}_{\ge 0} + \underbrace{x^T (A^T X + X A + C^T C - X B R^{-1} B^T X) x}_{\text{必须为0}}
$$

**步骤 3：得出结论（代数 Riccati 方程）**
为了使性能指标最小化，我们已经取了最优的 $u$，使得第一项完全平方项为 0。
为了满足最优性条件（Bellman 方程，即最优轨迹上的 Hamiltonian 恒为 0），**剩余项必须恒等于 0**。

这就导出了 **$H_2$ (LQR) 代数 Riccati 方程 (ARE)**：
$$
A^T X + X A + C^T C - X B R^{-1} B^T X = 0
$$

### 总结：$H_2$ 与 $H_\infty$ 推导的本质区别

请看下面这个对比表格，这是理解这两个方程最直观的方式：

| 步骤            | **$H_2$ (LQR) 控制**                                  | **$H_\infty$ 鲁棒控制**                                    |
| :-------------- | :---------------------------------------------------- | :--------------------------------------------------------- |
| **博弈对象**    | 只有**自己** ($u$)                                    | **自己** ($u$) vs **敌人** ($w$)                           |
| **优化目标**    | **Min**imize Cost                                     | **Min**imize $u$, **Max**imize $w$                         |
| **二次项符号**  | $u^T R u$ (**正号**，有最小值)                        | $-\gamma^2 w^T w$ (**负号**，有最大值)                     |
| **最优解**      | $u^* = -R^{-1} B^T X x$                               | $w^* = \gamma^{-2} B^T X x$                                |
| **配方结果**    | 平方项 **减去** 交叉项                                | 平方项 **加上** 交叉项                                     |
| **Riccati方程** | $A^T X + X A + C^T C \mathbf{-} X B R^{-1} B^T X = 0$ | $A^T X + X A + C^T C \mathbf{+} \gamma^{-2} X B B^T X = 0$ |
| **物理含义**    | **消耗**能量以达到稳态                                | 必须**对抗**这一项增加的干扰能量                           |

你可以看到，推导的骨架（积分转微分、Lyapunov、配方）是一模一样的。唯一的区别在于**这一项**：
*   $H_2$ 是 $- XBR^{-1}B^TX$：控制量把能量“拿走”了（消耗掉了）。
*   $H_\infty$ 是 $+ \gamma^{-2}XBB^TX$：干扰量把能量“注入”进来了（需要 $X$ 足够强来压制这个正项）。
