# 为什么在现代鲁棒控制中，控制器设计往往归结为求解一两个 Riccati 方程？——为什么要研究Riccati方程

### 自己总结

现代控制理论（特别是 $H_2$ 和 $H_\infty$ 控制）中，由于目标是系统对外部干扰 $w$ 的增益小于某个常数 $\gamma$，而这个增益的数学形式（大/小的定义）是 **$L_2$ 范数**（能量范数）

对于一个信号 $f(t)$，它的 $L_2$ 范数定义为：
\[
 \|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt} 
\]
这代表了信号在整个时间历程中的**总能量**。

*   **$H_\infty$**：不仅看 $L_2$ 范数，看的是**诱导 $L_2$ 范数**（输入到输出的放大倍数极值）。
*   **$H_2$**：看的是**脉冲响应的 $L_2$ 范数**（或者白噪声响应的 RMS 值）。

这个问题在于回答为什么要研究Riccati方程：因为Riccati方程是连接“时域能量（Lyapunov函数）”与“频域性能（范数）”的数学桥梁。

为什么他是桥梁呢，因为是我在连接时域能量和频域性能过程中**推导出的方程**，这个方程就叫Riccati方程。

### 推导过程（以 $H_\infty$ 控制为例）

#### **$L_2$ 范数**（即能量范数）形式性能指标，是时间积分形式

对于一个信号 $f(t)$，它的 **$L_2$ 范数定义**为：
$$
 \|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt} 
$$
这代表了信号在整个时间历程中的**总能量**。

当我们写下**$H_\infty$ 控制性能指标**：
\[
\frac{\|z\|_2}{\|w\|_2} < \gamma \implies \|z\|_2^2 - \gamma^2 \|w\|_2^2 < 0
\]
把它展开成积分，这就是所谓的**积分形式（Integral Form）**：
\[
\int_0^\infty \left( z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right) \, dt < 0
\]

*   **物理意义**：无论干扰 $w(t)$ 长什么样（只要它的总能量有限），系统响应输出 $z(t)$ 的总能量减去干扰总能量的 $\gamma^2$ 倍，这个差值在时间尽头（$t \to \infty$）必须是负的。即：**系统是一个“能量消耗者”，而不是“能量放大者”。**

#### 为什么要积分转微分：积分形式由于需要在$t=0$ 到 $t=\infty$ 的整个时间段内考察信号，很难用于设计控制器

**积分形式**（宏观）有一个巨大的缺点：**很难直接用于设计控制器。**
因为它要求我们在 $t=0$ 到 $t=\infty$ 的整个时间段内考察信号。要验证它，仿佛需要把仿真跑一万年。

为了设计控制器，我们需要把这个**“一辈子”**的要求，转化为**“每一瞬间”**（瞬时/微观）的要求。这就是**微分形式**。

#### 引入Lyapunov 函数，积分转微分，充分不必要条件

转化的桥梁是微积分基本定理。

我们引入一个 Lyapunov 函数 $V(x(t)) = x(t)^T X x(t)$，其中 $X > 0$。它代表系统在 $t$ 时刻内部存储的“虚构能量”。

**核心推导步骤：**

1.  **假设零初始状态**：通常假设 $x(0) = 0$，即初始 $V(x(0)) = 0$。
2.  **假设稳定性**：如果我们要求系统稳定，那么当 $t \to \infty$ 时，$x(t) \to 0$，即 $V(x(\infty)) = 0$。

根据微积分基本定理，我们可以写出一个恒等式：
\[
\int_0^\infty \dot{V}(x(t)) \, dt = V(x(\infty)) - V(x(0)) = 0
\]

3. **无中生有**：
   我们可以**把这个 $0$ 加到上面的“积分形式”中**，不改变不等式的方向：
   \[
   \underbrace{\int_0^\infty \left( z^T z - \gamma^2 w^T w \right) \, dt}_{\text{原始的积分形式性能指标}} + \underbrace{\int_0^\infty \dot{V}(x) \, dt}_{0} < 0 
   \]
   

   合并积分项：
   \[
   \int_0^\infty \underbrace{\left( \dot{V}(x(t)) + z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right)}_{J(t)} \, dt < 0
   \]

4. **充分条件（由整体到局部）**：
   要保证整个积分小于 0，一个**充分（Sufficient）**但不一定必要的办法是：让被积函数 $J(t)$ 在**每一分每一秒**都小于 0。

   这就是**微分形式**（耗散不等式）：
   \[
   \dot{V}(x) + z^T z - \gamma^2 w^T w < 0, \quad \forall t \ge 0
   \]

#### 将系统方程代入微分形式——最终的矩阵不等式 (LMI/Riccati)

现在我们有了微分形式，就可以代入系统方程 $\dot{x} = Ax + Bw$ 和 $z = Cx$ 了：

*   $V(x(t)) = x(t)^T X x(t)$
*   $\begin{align}
    \dot{V}(x) &= \dot{x}^T X x + x^T X \dot{x} \\
               &= (Ax+Bw)^T X x + x^T X (Ax+Bw)
    \end{align}$
*   $z^T z = x^T C^T C x$

代入微分不等式整理：
\[
x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0
\]
写成矩阵形式：
\[
\begin{bmatrix} x \\ w \end{bmatrix}^T \begin{bmatrix} A^T X + X A + C^T C & X B \\ B^T X & -\gamma^2 I \end{bmatrix} \begin{bmatrix} x \\ w \end{bmatrix} < 0
\]
为了使得上面的等式对任意的 $w$ 都成立，也就是说，即使是那个试图让左边尽可能变大（试图破坏 $<0$ 条件）的“最坏” $w$，也不能得逞。通过 Schur 补引理或者配方，这个不等式最终就变成了我们熟悉的 **Riccati 方程**（当取极值时）或 **线性矩阵不等式 (LMI)**。

#### 方法一：配方法得到代数 Riccati 不等式

不等式：
$$
x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0
$$
要保证上面的不等式对**任意**的 $w$ 都成立。也就是说，即使是那个试图让左边尽可能变大（试图破坏 $<0$ 条件）的“最坏” $w$，也不能得逞。

我们将原式看作**关于 $w$ 的二次函数**：
\[
f(w) = - \gamma^2 w^T w + 2 x^T X B w + x^T (A^T X + X A + C^T C) x
\]
注意 $w^T w$ 前面的系数是 $-\gamma^2$（负数），说明这是一个开口向下的抛物面，存在一个**极大值**。

**步骤 1：寻找最坏的干扰**
我们要找到让 $f(w)$ 最大的那个 $w^*$。对 $w$ 求导并令其为 0：
$$ \frac{\partial f}{\partial w} = -2\gamma^2 w + 2 B^T X x = 0 $$
解得最坏干扰（Worst-case Disturbance）：
$$ w^* = \gamma^{-2} B^T X x $$
*(物理意义：干扰 $w$ 会沿着梯度方向去攻击系统最脆弱的地方，这个方向由 $B^T X$ 决定)*

**步骤 2：代回原式（配方）**
我们将原式通过加一项减一项的方式（将\(w^T w\)配方成\(\| w - w^* \|^2\)）进行“配方”：
\[
f(w) = -\gamma^2 \| w - w^* \|^2 + \underbrace{x^T (A^T X + X A + C^T C) x + \gamma^2 (w^*)^T w^*}_{\text{剩余项}}
\]
把 $ w^* = \gamma^{-2} B^T X x $ 代入剩余项中的\(\gamma^2 (w^*)^T w^*\)中：
\[
\gamma^2 (w^*)^T w^* = \gamma^2 (\gamma^{-2} x^T X B) (\gamma^{-2} B^T X x) = \gamma^{-2} x^T X B B^T X x
\]
再将$ w^* = \gamma^{-2} B^T X x $ 代入\(f(w)\)，则原不等式等价于：
$$ -\gamma^2 \| w - \gamma^{-2} B^T X x \|^2 + x^T \left( A^T X + X A + C^T C + \gamma^{-2} X B B^T X \right) x < 0 $$

**步骤 3：得出结论**
为了保证总和小于 0，因为第一项 $-\gamma^2 \| \dots \|^2$ 总是非正的（最大也就是 0），所以我们必须要求**括号里的部分对于任意非零 $x$ 都是负定的**。

这就导出了**代数 Riccati 不等式 (ARI)**：
\[
A^T X + X A + C^T C + \gamma^{-2} X B B^T X < 0
\]


#### 总结

*   **积分形式**：$\int_0^\infty (z^T z - \gamma^2 w^T w) dt < 0$。这是**目标**（Performance），是定义，是我们要达到的总效果。
*   **微分形式**：$\dot{V} + z^T z - \gamma^2 w^T w < 0$。这是**手段**（Condition），是工具。

**逻辑是：** 只要我在每一瞬间都保证“能量的导数”加上“性能的惩罚”小于零（微分形式），那么我就能保证在整个时间长河里，系统的总增益是满足要求的（积分形式）。这就是为什么我们解 Riccati 方程就能保证 $H_\infty$ 性能。



### Gemini回答

在现代控制理论（特别是 $H_2$ 和 $H_\infty$ 控制）中，设计问题最终归结为求解一两个代数 Riccati 方程（ARE），并不是巧合，而是由系统的**无源性（Passivity）**、**耗散性（Dissipativity）**以及**对偶原理（Duality Principle）**共同决定的。

下面我从三个层面，为你深入浅出地推导和解释这个原因。

---

### 第一层面：从“能量”的角度（Lyapunov 理论与 Bounded Real Lemma）

控制理论最核心的概念是**稳定性**。我们要证明一个系统稳定，最通用的方法是找一个 Lyapunov 函数 $V(x) = x^T X x$，其中 $X > 0$ 代表“广义能量”的度量矩阵。

#### 1. 性能指标的转化
在 $H_\infty$ 控制中，我们的目标是让系统对外部干扰 $w$ 的增益小于某个常数 $\gamma$。数学上写为：
$$ \frac{\|z\|_2}{\|w\|_2} < \gamma \implies \|z\|_2^2 - \gamma^2 \|w\|_2^2 < 0 $$
这意味着系统的“输出能量”必须小于“输入能量”的 $\gamma^2$ 倍。

#### 2. 微分形式与耗散不等式
将上述积分形式转化为微分形式（耗散不等式），我们需要存在一个 $V(x) = x^T X x$，使得沿着系统轨迹的导数满足：
$$ \dot{V}(x) + z^Tz - \gamma^2 w^Tw < 0 $$
如果把系统方程 $\dot{x} = Ax + Bw, z = Cx$ 代入上式，你会得到一个关于 $X$ 的矩阵不等式。

**注：**这里的积分形式指的是 $H_\infty$ 性能指标在**时域上的数学定义**。它描述的是系统在整个时间轴（$0$ 到 $\infty$）上的累积行为。

#### 3. Bounded Real Lemma (有界实引理)
这是控制理论中最著名的引理之一。它告诉我们：频域上的 $H_\infty$ 范数条件，**等价于**时域上存在一个正定矩阵 $X$ 满足某个**代数 Riccati 不等式（ARI）**。

而在最优控制设计中，我们要寻找最优解（或者处于边界情况的解），不等式中的“小于号”往往取到“等号”。于是，**不等式变成了方程**：
$$ A^T X + X A + X (\gamma^{-2} B_1 B_1^T - B_2 B_2^T) X + C^T C = 0 $$
这就是为什么控制设计最终变成了找这个 $X$。这个 $X$ 定义了系统的“能量地形图”，告诉控制器如何根据当前的能量状态去施加控制力。

---

### 第二层面：从“对偶”的角度（为什么是两个？）

你可能会问：*“好，我理解了需要解一个方程来定义能量，那为什么往往是**两个** Riccati 方程呢？”*

这是因为现代控制系统设计通常包含两个解耦的任务：**控制（Control）** 和 **估计（Estimation）**。

#### 1. 第一个方程：全状态反馈 (State Feedback)
假设你能看到系统所有的状态 $x$，你需要设计一个控制律 $u = Kx$。
*   你需要求解一个 Riccati 方程（记解为 $X$）。
*   这个 $X$ 解决了“调节（Regulation）”问题：即在存在干扰的情况下，如何用最小的代价把状态 $x$ 拉回零点。
*   物理意义：**控制增益 $K$ 是由 $X$ 决定的（通常 $K = -B^T X$）。**

#### 2. 第二个方程：观测器设计 (Output Injection / Filtering)
现实中，你只能看到输出 $y$，看不到内部状态 $x$。你需要设计一个观测器（Observer）来估计状态。
*   根据**对偶原理（Duality）**，估计问题数学上等价于控制问题（把矩阵转置，时间反向）。
*   因此，你需要求解第二个 Riccati 方程（记解为 $Y$ 或 $P$）。
*   这个 $Y$ 解决了“滤波（Filtering）”问题：即在存在噪声的情况下，如何最准地估计状态。
*   物理意义：**观测器增益 $L$ 是由 $Y$ 决定的（通常 $L = -Y C^T$）。**

#### 3. $H_\infty$ 的特殊性 (DGKF 解法)
在经典的 LQG ($H_2$) 控制中，分离原理（Separation Principle）完美成立：你可以独立设计控制器和观测器。

在 $H_\infty$ 控制中（这是鲁棒控制的核心），情况稍微复杂一点。1989年著名的 **DGKF 论文**（Doyle, Glover, Khargonekar, Francis）证明了一个令人震惊的结论：
即使在处理最坏情况干扰时，输出反馈 $H_\infty$ 控制器依然可以分解为两个耦合的 Riccati 方程：
1.  一个关于 $X$（控制 Riccati）：处理干扰对状态的影响。
2.  一个关于 $Y$（滤波 Riccati）：处理测量噪声和干扰估计误差。

只要这两个方程都有正定解，且满足谱半径条件 $\rho(XY) < \gamma^2$（这是一个耦合条件，意味着观测误差不能被控制回路放大太多），那么鲁棒控制器就存在。

---

### 第三层面：从“博弈论”的角度（直观理解非线性项）

为什么方程里会有非线性的二次项 $XRX$？

#### 1. LQR/H2：最小化问题
在 LQR 中，我们在做一个单方面的优化：作为工程师，我们在寻找 $u$ 来**最小化**代价函数 $J$。
$$ \min_u J $$
这种“平方和”的最小化问题，对应的就是二次型函数的极值点，导出的就是 Riccati 方程中的二次项 $-X B R^{-1} B^T X$。这代表了“控制所能带来的能量衰减”。

#### 2. H-infinity：极大极小博弈 (Min-Max Game)
在鲁棒控制中，我们玩的是一个**零和博弈（Zero-sum Game）**：
*   **你（控制器 $u$）**：试图**最小化**误差。
*   **上帝/自然界（干扰 $w$）**：试图**最大化**误差（寻找最坏情况）。

数学表达为：
$$ \min_u \max_w J $$

这个博弈在数学上导致了 Riccati 方程中出现了两个符号相反的二次项：
$$ \underbrace{- X B_2 B_2^T X}_{\text{控制试图减少能量}} + \underbrace{\gamma^{-2} X B_1 B_1^T X}_{\text{干扰试图增加能量}} $$

这两个二次项的对抗，决定了 Riccati 方程解的存在性。
*   如果 $X$ 存在，说明“控制”赢了，不管“干扰”如何最大化破坏，系统还是稳定的。
*   如果 Riccati 方程无解（发散），说明“干扰”赢了，对于给定的 $\gamma$，你无法设计出控制器来稳定系统。

---

### 教授总结

简单来说，在现代鲁棒控制中，控制器设计归结为求解一两个 Riccati 方程，是因为：

1.  **数学本质**：Riccati 方程是**Lyapunov 稳定性理论**和**性能指标（范数界）**相结合的产物。它是将复杂的微分不等式转化为代数方程的唯一标准工具。
2.  **结构对偶**：为了处理**全状态反馈**和**状态估计**这两个互为对偶的基本问题，我们需要分别求解两个方程（一个算控制增益 $K$，一个算观测增益 $L$）。
3.  **博弈机制**：Riccati 方程中的二次项完美刻画了“控制输入”与“最坏干扰”之间的**极大极小博弈**平衡点。

所以，当你解出那两个矩阵 $X$ 和 $Y$ 时，你不仅仅是在解方程，你实际上是在计算系统在最坏情况下的**广义能量边界**和**最优观测误差协方差**。这就是鲁棒控制的精髓所在。



# $H_2$ 控制和$H_\infty$ 控制关注点不同，但都是$L_2$ 范数

### 自己总结

*   **$H_\infty$**：不仅看 $L_2$ 范数，看的是**诱导 $L_2$ 范数**（输入到输出的放大倍数极值）。
*   **$H_2$**：看的是**脉冲响应的 $L_2$ 范数**（或者白噪声响应的 RMS 值）。

**一句话记住：$H_\infty$ 削峰（Peak），$H_2$ 减面（Area）。**



### Gemini回答

这是一个非常棒的对比问题！弄清楚 $H_2$ 和 $H_\infty$ 的物理意义区别，是理解现代控制理论分水岭的关键。

作为教授，我可以一句话概括：
*   $H_\infty$ 控制关注的是**“最坏情况（Worst-case）”**（墨菲定律：如果事情可能变坏，它一定会变坏）。
*   $H_2$ 控制关注的是**“平均情况（Average Case）”**或者**“随机情况（Stochastic）”**。

具体来说，在 $H_2$ 控制中，我们关注的指标主要有以下两种完全等价的理解方式：

---

### 1. 随机视角：对白噪声的响应（功率/方差）

这是 $H_2$ 控制最经典的物理背景（对应 LQG 控制）。

*   **输入 $w$**：假设外部干扰 $w(t)$ 是**单位强度的白噪声**（White Gaussian Noise）。这是一种在频谱上能量均匀分布的随机信号。
*   **关注的指标**：输出 $z(t)$ 的**平均功率**（Average Power）或**稳态方差**（Steady-state Variance）。

数学表达为：
$$ \|G\|_2^2 = \lim_{T \to \infty} \frac{1}{T} \int_0^T E[z(t)^T z(t)] \, dt = E[z_{ss}^T z_{ss}] $$

**教授直观解释：**
想象你在设计汽车悬挂。
*   **$H_\infty$ 设计**：你假设路面上有一个**最恶心、最针对你车型**的大坑或减速带，你要保证汽车过这个坑时，车身振动幅度不超过某个极限。你怕的是“万一”。
*   **$H_2$ 设计**：你假设路面是**随机的粗糙路面**（白噪声），你要保证在这一路开过去的过程中，车身振动的**平均能量**（RMS值）最小，让乘客全程感觉最舒服。你关心的是“日常”。

---

### 2. 确定性视角：对脉冲信号的响应（总能量）

如果我们不把输入看作随机噪声，而是看作确定的信号，$H_2$ 范数也有明确的定义。

*   **输入 $w$**：假设外部干扰 $w(t)$ 是一个**脉冲信号**（Impulse, $\delta(t)$）。
*   **关注的指标**：输出 $z(t)$（即脉冲响应 $g(t)$）的 **$L_2$ 范数**（总能量）。

数学表达（根据 Parseval 定理，时域能量等于频域能量）：
$$ \|G\|_2^2 = \int_0^\infty \text{trace}(g(t)^T g(t)) \, dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} \text{trace}(G(j\omega)^* G(j\omega)) \, d\omega $$

**教授直观解释：**
这就像是用锤子猛击一下系统（脉冲输入），然后看系统会“颤抖”多久。
*   $H_2$ 指标就是要最小化这个颤抖过程中的**总能量累积**。
*   这也解释了为什么 $H_2$ 范数等于波特图（Bode Plot）幅频曲线下方的**面积**（积分）。

---

### 3. $H_2$ 与 $H_\infty$ 的决定性区别

为了让你彻底明白，我们把它们放在一起对比：

| 特性             | **$H_\infty$ 控制**                      | **$H_2$ 控制 (LQR/LQG)**                                  |
| :--------------- | :--------------------------------------- | :-------------------------------------------------------- |
| **关注的输入**   | **最坏的** 能量有界信号（Worst-case）    | **白噪声** 或 **脉冲信号**                                |
| **关注的输出**   | 输出能量与输入能量的 **最大比值** (Gain) | 输出的 **平均功率** (Variance) 或 **总能量**              |
| **频域几何意义** | 波特图曲线的 **最高峰值** (Peak)         | 波特图曲线下方的 **面积** (Area)                          |
| **设计哲学**     | **鲁棒性**：防止系统在特定频率共振或发散 | **性能**：让系统在宽频带内的平均误差最小                  |
| **数学工具**     | Riccati 不等式 / 两个 Riccati 方程       | 一个 Riccati 方程 (Controllability/Observability Gramian) |

### 4. 为什么 $H_2$ 不需要那个 $\gamma$ ?

你可能注意到了，$H_\infty$ 中有个 $\gamma$ 作为上限，而 $H_2$ 通常是直接最小化。

*   在 $H_2$ 中，我们计算的是**Gramian 矩阵**（比如可控性 Gramian $P$）：
    $$ A P + P A^T + B B^T = 0 $$
    这里是一个**Lyapunov 方程**，而不是含有二次项 $P R P$ 的 Riccati 方程（在纯分析时）。
*   $H_2$ 范数就是 $\|G\|_2 = \sqrt{\text{trace}(C P C^T)}$。
*   只有当我们要做 $H_2$ **综合（设计控制器）**时，才会因为要最小化这个范数，导出标准的 Riccati 方程（这就是著名的 LQR/LQG 问题）。

### 总结

*   **$H_\infty$**：不仅看 $L_2$ 范数，看的是**诱导 $L_2$ 范数**（输入到输出的放大倍数极值）。
*   **$H_2$**：看的是**脉冲响应的 $L_2$ 范数**（或者白噪声响应的 RMS 值）。

**一句话记住：$H_\infty$ 削峰（Peak），$H_2$ 减面（Area）。**





# $H_\infty$ 时域性能指标：对外界干扰的积分形式， **$L_2$ 范数**（即能量范数），Riccati方程推导



这里的积分形式指的是什么？

你好！这是一个非常关键的数学细节。作为教授，我很高兴你能注意到这一点，因为这正是理解**耗散性理论（Dissipativity Theory）**的核心。

这里的“积分形式”，指的就是 $H_\infty$ 性能指标在**时域上的数学定义**。它描述的是系统在整个时间轴（$0$ 到 $\infty$）上的累积行为。

让我用最直观的数学语言把这个过程拆解开来。

---

### 1. 什么是“积分形式”？

在 $H_\infty$ 控制中，我们关注的是信号的 **$L_2$ 范数**（即能量范数）。

对于一个信号 $f(t)$，它的 $L_2$ 范数定义为：
$$ \|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt} $$
这代表了信号在整个时间历程中的**总能量**。

当我们写下性能指标：
$$ \frac{\|z\|_2}{\|w\|_2} < \gamma \implies \|z\|_2^2 - \gamma^2 \|w\|_2^2 < 0 $$

即系统的外部干扰 $w$ 的增益小于某个常数 $\gamma$

把它展开成积分，这就是所谓的**积分形式（Integral Form）**：
$$ \int_0^\infty \left( z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right) \, dt < 0 $$

*   **物理意义**：无论干扰 $w(t)$ 长什么样（只要它的总能量有限），系统响应输出 $z(t)$ 的总能量减去干扰总能量的 $\gamma^2$ 倍，这个差值在时间尽头（$t \to \infty$）必须是负的。即：**系统是一个“能量消耗者”，而不是“能量放大者”。**

---

### 2. 为什么要转化？（从宏观到微观）

**积分形式**（宏观）有一个巨大的缺点：**很难直接用于设计控制器。**
因为它要求我们在 $t=0$ 到 $t=\infty$ 的整个时间段内考察信号。要验证它，仿佛需要把仿真跑一万年。

为了设计控制器，我们需要把这个**“一辈子”**的要求，转化为**“每一瞬间”**（瞬时/微观）的要求。这就是**微分形式**。

---

### 3. 如何转化？（Lyapunov 函数的魔法）

转化的桥梁是微积分基本定理。

我们引入一个 Lyapunov 函数 $V(x(t)) = x(t)^T X x(t)$，其中 $X > 0$。它代表系统在 $t$ 时刻内部存储的“虚构能量”。

**核心推导步骤：**

1.  **假设零初始状态**：通常假设 $x(0) = 0$，即初始 $V(x(0)) = 0$。
2.  **假设稳定性**：如果我们要求系统稳定，那么当 $t \to \infty$ 时，$x(t) \to 0$，即 $V(x(\infty)) = 0$。

根据微积分基本定理，我们可以写出一个恒等式：
$$ \int_0^\infty \dot{V}(x(t)) \, dt = V(x(\infty)) - V(x(0)) = 0 $$

3.  **无中生有**：
    我们可以把这个 $0$ 加到上面的“积分形式”中，不改变不等式的方向：
    $$ \underbrace{\int_0^\infty \left( z^T z - \gamma^2 w^T w \right) \, dt}_{\text{原始性能指标}} + \underbrace{\int_0^\infty \dot{V}(x) \, dt}_{0} < 0 $$

    合并积分项：
    $$ \int_0^\infty \underbrace{\left( \dot{V}(x(t)) + z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right)}_{J(t)} \, dt < 0 $$

4.  **充分条件（由整体到局部）**：
    要保证整个积分小于 0，一个**充分（Sufficient）**但**不一定必要**的办法是：让被积函数 $J(t)$ 在**每一分每一秒**都小于 0。

    这就是**微分形式**（耗散不等式）：
    $$ \dot{V}(x) + z^T z - \gamma^2 w^T w < 0, \quad \forall t \ge 0 $$

---

### 4. 最终的矩阵不等式 (LMI/Riccati)

现在我们有了微分形式，就可以代入系统方程 $\dot{x} = Ax + Bw$ 和 $z = Cx$ 了：
**注**：这里的系统方程本来应该是输入\(u\)，但是由于我们是看扰动的影响，所以变成了\(w\)。可是为什么不是$z = Cx+Dw$呢？
答：已经解决，在本md文件里，搜索“系统方程为什么是$z = Cx$而不是$z = Cx+Dw$呢？$D=0$意味着什么？”



*   $\dot{V}(x) = \dot{x}^T X x + x^T X \dot{x} = (Ax+Bw)^T X x + x^T X (Ax+Bw)$
*   $z^T z = x^T C^T C x$

代入微分不等式整理：
$$ x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0 $$

写成矩阵形式：
$$ \begin{bmatrix} x \\ w \end{bmatrix}^T \begin{bmatrix} A^T X + X A + C^T C & X B \\ B^T X & -\gamma^2 I \end{bmatrix} \begin{bmatrix} x \\ w \end{bmatrix} < 0 $$

通过 Schur 补引理或者配方，这个不等式最终就变成了我们熟悉的 **Riccati 方程**（当取极值时）或 **线性矩阵不等式 (LMI)**。

### 教授总结

*   **积分形式**：$\int_0^\infty (z^T z - \gamma^2 w^T w) dt < 0$。这是**目标**（Performance），是定义，是我们要达到的总效果。
*   **微分形式**：$\dot{V} + z^T z - \gamma^2 w^T w < 0$。这是**手段**（Condition），是工具。

**逻辑是：** 只要我在每一瞬间都保证“能量的导数”加上“性能的惩罚”小于零（微分形式），那么我就能保证在整个时间长河里，系统的总增益是满足要求的（积分形式）。这就是为什么我们解 Riccati 方程就能保证 $H_\infty$ 性能。

# 系统方程为什么是$z = Cx$而不是$z = Cx+Dw$呢？$D=0$意味着什么？

### 自己总结

如果\(D \neq 0\)，意味着扰动输入\(w\)的变化能直接影响系统输出\(z\)，直通了。

* 如果干扰 $w$ 能通过直通项 $D$ 直接放大并传到输出 $z$，那么无论你的控制器（反馈回路）设计得多么完美，整个系统的 $H_\infty$ 增益永远不可能小于 $\|D\|$。这给 $\gamma$ 设定了一个物理极限。
* 且Riccati方程推导会变复杂，为了解决这个问题，可以进行变量代换，转换成\(D = 0\)的形式。
  重新定义一个新的干扰 $\tilde{w}$ 或者一个新的输出 $\tilde{z}$，把 $D$ 项消掉，把它变成一个等价的 $D=0$ 的标准问题来解。



## Gemini回答

简单的回答是：**为了教学和推导的“清爽”，我们刚才默认了 $D=0$（即系统是严格真有理系统）。**

但在实际工程和更通用的理论中，你的直觉是对的：**$z = Cx + Dw$ 才是更完整的形式。**

让我详细解释一下为什么刚才忽略了 $D$，以及如果把 $D$ 加进来，数学推导会发生什么变化（你会发现这会让公式变丑，但物理本质不变）。

---

### 1. 为什么通常先假设 $D=0$？

在很多教材（包括这本 PDF 的简化推导部分）中，假设 $D=0$ 主要基于两个原因：

#### A. 物理实现的限制（严格真系统）
在物理世界中，大部分系统都有**惯性**。
*   $z = Cx$ 意味着：干扰 $w$ 必须先改变状态 $x$（比如给物体加速、加热），状态改变了，输出 $z$ 才会改变。这是一个积分过程，需要时间。
*   $z = Cx + Dw$ 意味着：干扰 $w$ 会**瞬间**直接出现在输出 $z$ 上（直通车）。
    *   例如：在电路中，电阻分压是瞬间的（$D \neq 0$）；但在机械系统中，力推一个质量块，位置不会瞬间突变（$D=0$）。
    *   为了简化分析，我们常假设系统是“严格真（Strictly Proper）”的，即高频增益为 0。

#### B. 数学推导的“干净”程度
如果不假设 $D=0$，在做配方（Completing the square）时会多出很多交叉项（Cross-terms），导致 Riccati 方程的系数变得非常复杂，容易把初学者绕晕。

---

### 2. 如果 $D \neq 0$，推导会变成什么样？（硬核数学演示）

让我们来推导一下带有 $D$ 的情况，你会看到区别在哪里。

**系统方程：**
$$\dot{x} = Ax + Bw$$
$$ z = Cx + Dw $$

**性能指标微分形式（耗散不等式）：**
$$ \dot{V}(x) + z^T z - \gamma^2 w^T w < 0 $$

把 $z = Cx + Dw$ 代入 $z^T z$：
$$ \begin{aligned} z^T z &= (Cx + Dw)^T (Cx + Dw) \\ &= x^T C^T C x + x^T C^T D w + w^T D^T C x + w^T D^T D w \end{aligned} $$

**代入耗散不等式：**
$$ \underbrace{(x^T A^T + w^T B^T)X x + x^T X (Ax + Bw)}_{\dot{V}(x)} + \underbrace{(x^T C^T C x + 2x^T C^T D w + w^T D^T D w)}_{z^T z} - \gamma^2 w^T w < 0 $$

整理后，写成矩阵形式：

$$ \begin{bmatrix} x \\ w \end{bmatrix}^T \begin{bmatrix} A^T X + X A + C^T C & XB + C^T D \\ B^T X + D^T C & D^T D - \gamma^2 I \end{bmatrix} \begin{bmatrix} x \\ w \end{bmatrix} < 0 $$

---

### 3. 两个关键的区别

对比一下 $D=0$ 和 $D \neq 0$ 的矩阵不等式：

*   **$D=0$ 时（刚才讲的）：**
    $$ \begin{bmatrix} \dots & XB \\ B^T X & -\gamma^2 I \end{bmatrix} < 0 $$

*   **$D \neq 0$ 时（真实情况）：**
    $$ \begin{bmatrix} \dots & XB + C^T D \\ B^T X + D^T C & D^T D - \gamma^2 I \end{bmatrix} < 0 $$

这里有两个巨大的影响：

#### 第一点：$\gamma$ 的下界限制
看右下角的块：$D^T D - \gamma^2 I$ 必须是负定的。
这意味必须满足：
$$ \gamma^2 I > D^T D \implies \gamma > \|D\|_2 $$
**物理意义：** 如果干扰 $w$ 能通过直通项 $D$ 直接放大并传到输出 $z$，那么无论你的控制器（反馈回路）设计得多么完美，整个系统的 $H_\infty$ 增益永远不可能小于 $\|D\|$。这给 $\gamma$ 设定了一个物理极限。

#### 第二点：Riccati 方程变复杂了
当我们根据 Schur 补引理把上面那个复杂的矩阵变回 Riccati 方程时，$B$ 会被替换成 $B + C^T D (\dots)$ 这样复杂的项。

通常为了处理这种情况，我们会做一个**变量代换**（Loop Shifting / Coordinate Transformation）：
重新定义一个新的干扰 $\tilde{w}$ 或者一个新的输出 $\tilde{z}$，把 $D$ 项消掉，把它变成一个等价的 $D=0$ 的标准问题来解。

### 教授总结

1.  **本来应该是 $z = Cx + Dw$ 吗？**
    是的，绝对正确。这就是最一般的形式。

2.  **为什么这里用 $z=Cx$？**
    *   为了**教学方便**：避免处理 $XB + C^T D$ 这种交叉项。
    *   为了**强调核心逻辑**：Riccati 方程的来源是 $A^T X + XA$ 和 $-\gamma^{-2} B B^T$ 的对抗，这一点无论有没有 $D$ 都是一样的。

3.  **工程启示**：
    如果你在设计控制器时发现 Riccati 方程解不出来（报错），记得检查一下是不是你的 $\gamma$ 设置得太小了，甚至比直接馈通项 $\|D\|$ 还小。如果是那样，神仙也救不了，必须放宽 $\gamma$ 的要求。





# 代数黎卡提方程推导\(H_{\infty}\)

### 自己总结

现代控制理论（特别是 $H_2$ 和 $H_\infty$ 控制）中，由于目标是系统对外部干扰 $w$ 的增益小于某个常数 $\gamma$，而这个增益的数学形式（大/小的定义）是 **$L_2$ 范数**（能量范数）

对于一个信号 $f(t)$，它的 $L_2$ 范数定义为：
$$
 \|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt} 
$$
这代表了信号在整个时间历程中的**总能量**。

*   **$H_\infty$**：不仅看 $L_2$ 范数，看的是**诱导 $L_2$ 范数**（输入到输出的放大倍数极值）。
*   **$H_2$**：看的是**脉冲响应的 $L_2$ 范数**（或者白噪声响应的 RMS 值）。

这个问题在于回答为什么要研究Riccati方程：因为Riccati方程是连接“时域能量（Lyapunov函数）”与“频域性能（范数）”的数学桥梁。

为什么他是桥梁呢，因为是我在连接时域能量和频域性能过程中**推导出的方程**，这个方程就叫Riccati方程。

### 推导过程（以 $H_\infty$ 控制为例）

#### **$L_2$ 范数**（即能量范数）形式性能指标，是时间积分形式

对于一个信号 $f(t)$，它的 **$L_2$ 范数定义**为：
$$
\|f\|_2 = \sqrt{\int_0^\infty f(t)^T f(t) \, dt}
$$
这代表了信号在整个时间历程中的**总能量**。

当我们写下**$H_\infty$ 控制性能指标**：
$$
\frac{\|z\|_2}{\|w\|_2} < \gamma \implies \|z\|_2^2 - \gamma^2 \|w\|_2^2 < 0
$$
把它展开成积分，这就是所谓的**积分形式（Integral Form）**：
$$
\int_0^\infty \left( z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right) \, dt < 0
$$

*   **物理意义**：无论干扰 $w(t)$ 长什么样（只要它的总能量有限），系统响应输出 $z(t)$ 的总能量减去干扰总能量的 $\gamma^2$ 倍，这个差值在时间尽头（$t \to \infty$）必须是负的。即：**系统是一个“能量消耗者”，而不是“能量放大者”。**

#### 为什么要积分转微分：积分形式由于需要在$t=0$ 到 $t=\infty$ 的整个时间段内考察信号，很难用于设计控制器

**积分形式**（宏观）有一个巨大的缺点：**很难直接用于设计控制器。**
因为它要求我们在 $t=0$ 到 $t=\infty$ 的整个时间段内考察信号。要验证它，仿佛需要把仿真跑一万年。

为了设计控制器，我们需要把这个**“一辈子”**的要求，转化为**“每一瞬间”**（瞬时/微观）的要求。这就是**微分形式**。

#### 引入Lyapunov 函数，积分转微分，充分不必要条件

转化的桥梁是微积分基本定理。

我们引入一个 Lyapunov 函数 $V(x(t)) = x(t)^T X x(t)$，其中 $X > 0$。它代表系统在 $t$ 时刻内部存储的“虚构能量”。

**核心推导步骤：**

1.  **假设零初始状态**：通常假设 $x(0) = 0$，即初始 $V(x(0)) = 0$。
2.  **假设稳定性**：如果我们要求系统稳定，那么当 $t \to \infty$ 时，$x(t) \to 0$，即 $V(x(\infty)) = 0$。

根据微积分基本定理，我们可以写出一个恒等式：
$$
\int_0^\infty \dot{V}(x(t)) \, dt = V(x(\infty)) - V(x(0)) = 0
$$

3. **无中生有**：
   我们可以**把这个 $0$ 加到上面的“积分形式”中**，不改变不等式的方向：
   $$
   \underbrace{\int_0^\infty \left( z^T z - \gamma^2 w^T w \right) \, dt}_{\text{原始的积分形式性能指标}} + \underbrace{\int_0^\infty \dot{V}(x) \, dt}_{0} < 0 
   $$
   

   合并积分项：
   $$
   \int_0^\infty \underbrace{\left( \dot{V}(x(t)) + z(t)^T z(t) - \gamma^2 w(t)^T w(t) \right)}_{J(t)} \, dt < 0
   $$

4. **充分条件（由整体到局部）**：
   要保证整个积分小于 0，一个**充分（Sufficient）**但不一定必要的办法是：让被积函数 $J(t)$ 在**每一分每一秒**都小于 0。

   这就是**微分形式**（耗散不等式）：
   $$
   \dot{V}(x) + z^T z - \gamma^2 w^T w < 0, \quad \forall t \ge 0
   $$

#### 将系统方程代入微分形式——最终的矩阵不等式 (LMI/Riccati)

现在我们有了微分形式，就可以代入系统方程 $\dot{x} = Ax + Bw$ 和 $z = Cx$ 了：

*   $V(x(t)) = x(t)^T X x(t)$
*   $\begin{align}
    \dot{V}(x) &= \dot{x}^T X x + x^T X \dot{x} \\
               &= (Ax+Bw)^T X x + x^T X (Ax+Bw)
    \end{align}$
*   $z^T z = x^T C^T C x$

代入微分不等式整理：
$$
x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0
$$
写成矩阵形式：
$$
\begin{bmatrix} x \\ w \end{bmatrix}^T \begin{bmatrix} A^T X + X A + C^T C & X B \\ B^T X & -\gamma^2 I \end{bmatrix} \begin{bmatrix} x \\ w \end{bmatrix} < 0
$$
为了使得上面的等式对任意的 $w$ 都成立，也就是说，即使是那个试图让左边尽可能变大（试图破坏 $<0$ 条件）的“最坏” $w$，也不能得逞。通过 Schur 补引理或者配方，这个不等式最终就变成了我们熟悉的 **Riccati 方程**（当取极值时）或 **线性矩阵不等式 (LMI)**。

#### 方法一：配方法得到代数 Riccati 不等式

不等式：
$$
x^T (A^T X + X A + C^T C) x + w^T B^T X x + x^T X B w - \gamma^2 w^T w < 0
$$
要保证上面的不等式对**任意**的 $w$ 都成立。也就是说，即使是那个试图让左边尽可能变大（试图破坏 $<0$ 条件）的“最坏” $w$，也不能得逞。

我们将原式看作**关于 $w$ 的二次函数**：
$$
f(w) = - \gamma^2 w^T w + 2 x^T X B w + x^T (A^T X + X A + C^T C) x
$$
注意 $w^T w$ 前面的系数是 $-\gamma^2$（负数），说明这是一个开口向下的抛物面，存在一个**极大值**。

**步骤 1：寻找最坏的干扰**
我们要找到让 $f(w)$ 最大的那个 $w^*$。对 $w$ 求导并令其为 0：
$$ \frac{\partial f}{\partial w} = -2\gamma^2 w + 2 B^T X x = 0 $$
解得最坏干扰（Worst-case Disturbance）：
$$ w^* = \gamma^{-2} B^T X x $$
*(物理意义：干扰 $w$ 会沿着梯度方向去攻击系统最脆弱的地方，这个方向由 $B^T X$ 决定)*

**步骤 2：代回原式（配方）**
我们将原式通过加一项减一项的方式（将\(w^T w\)配方成\(\| w - w^* \|^2\)）进行“配方”：
$$
f(w) = -\gamma^2 \| w - w^* \|^2 + \underbrace{x^T (A^T X + X A + C^T C) x + \gamma^2 (w^*)^T w^*}_{\text{剩余项}}
$$
把 $ w^* = \gamma^{-2} B^T X x $ 代入剩余项中的\(\gamma^2 (w^*)^T w^*\)中：
$$
\gamma^2 (w^*)^T w^* = \gamma^2 (\gamma^{-2} x^T X B) (\gamma^{-2} B^T X x) = \gamma^{-2} x^T X B B^T X x
$$
再将$ w^* = \gamma^{-2} B^T X x $ 代入\(f(w)\)，则原不等式等价于：
$$ -\gamma^2 \| w - \gamma^{-2} B^T X x \|^2 + x^T \left( A^T X + X A + C^T C + \gamma^{-2} X B B^T X \right) x < 0 $$

**步骤 3：得出结论**
为了保证总和小于 0，因为第一项 $-\gamma^2 \| \dots \|^2$ 总是非正的（最大也就是 0），所以我们必须要求**括号里的部分对于任意非零 $x$ 都是负定的**。

这就导出了**代数 Riccati 不等式 (ARI)**：
$$
A^T X + X A + C^T C + \gamma^{-2} X B B^T X < 0
$$
